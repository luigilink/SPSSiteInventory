# Security Policy

## Supported Versions

SPSSiteInventory is pre-1.0. Security fixes are applied to the latest release only.

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

SPSSiteInventory is a **read-only** assessment toolkit that runs on SharePoint Server farm servers with farm-account privileges. We take vulnerabilities seriously.

**Please do not open a public GitHub issue for security vulnerabilities.**

Use the **GitHub Security Advisories** form (preferred): open the repository's **Security** tab and choose **Report a vulnerability**.

When reporting, please include:

- a description of the issue and its impact;
- steps to reproduce;
- affected version(s) and environment (SharePoint build, PowerShell version).

We will acknowledge the report, investigate, and coordinate a fix and disclosure timeline with you.
